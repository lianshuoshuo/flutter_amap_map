## 0.0.1

- Added native AMap views for Android, iOS and HarmonyOS NEXT with privacy-aware initialization, independent map controllers and lifecycle events.
- Added camera movement, padded bounds fitting, gesture attribution, standard and satellite maps, gesture and control options, zoom limits and map approval numbers.
- Added PNG markers, polylines, meter-based circles and polygons with per-map ID updates and removal. Projection works in both directions between GCJ-02 coordinates and map-local Flutter logical pixels.
- Added place suggestions, keyword and nearby search with pagination, place details, forward geocoding and structured reverse geocoding.
- Included a self-contained interactive example and documented platform setup. The plugin's own code and original marker artwork use the MIT license. [Example](example/README.md) · [Platform setup](doc/platforms.md)
